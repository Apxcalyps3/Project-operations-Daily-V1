# 🟢 Operations Daily

### *Simplex & Operations Research Solver System*

**Operations Daily** is a specialized, web-based educational tool designed to simplify the complexities of Operations Research (OR). Featuring a high-contrast Retro-Cyberpunk aesthetic, this platform provides a powerful interface for solving Linear Programming (LP) and Integer Programming (IP) problems while offering a deep dive into the mathematical steps required to reach optimality.

---

## 🎯 The Mission
The aim of **Operations Daily** is to bridge the gap between complex mathematical theory and practical application. Unlike standard calculators that only provide a final answer, our system focuses on the **educational process**. 

By providing detailed Simplex tableaus, row-by-row operations, and interactive graphical visualizations, we empower students and professionals to not only find the solution but to understand the *logic* behind the algorithm.

---

## ✨ Core Features
- **LP Solver:** Handles Maximization and Minimization problems using Simplex, Dual Simplex, and Big M methods.
- **IP Solver:** Solves Integer Programming models using Cutting Plane and Branch & Bound techniques.
- **Step-by-Step Tableaus:** View every iteration of the Simplex method with explicit row operation text and pivot explanations.
- **Graphical Visualization:** Interactive, monochromatic green 2D graphs with shaded feasible regions for 2-variable models.
- **Daily Challenge:** A new, randomized OR problem generated every 24 hours to keep your skills sharp.
- **Persistent History:** Securely save your solver results and challenge progress to the cloud via Firebase.

## 🛠️ Roadmap & Future Developments
We are actively working to expand **Operations Daily** into a comprehensive OR suite. Future versions will move beyond LP/IP models to include:

- **Transportation Models:** Specialized solvers for Northwest Corner, Least Cost, and Vogel’s Approximation (VAM) methods.
- **Assignment Problems:** Full implementation of the Hungarian Method.
- **Network Analysis:** Interactive PERT/CPM chart generators, Shortest Path (Dijkstra), and Max Flow algorithms.
- **Goal Programming:** Multi-objective optimization modules.
- **Advanced Challenges:** Scenario-based challenges for Inventory Management and Queuing Theory.
